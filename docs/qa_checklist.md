## Правила фиксации результата

* «Пройдено» — фактический результат совпал с ожидаемым.
* «Не пройдено» — обнаружено несоответствие.
* «Не проверено» — тест ещё не выполнялся.

При обнаружении ошибки создать Issue с описанием шагов воспроизведения, ожидаемого результата и фактического результата.
